# Платформа ASDIC™

Рабочее место для пути компании из точки A в точку B по методу ASDIC™: Analysis → Strategy → Design → Interaction → Control. Каждая задача внутри этапа окрашена светофором: красное решает и подписывает человек, жёлтое делает ИИ и проверяет человек, зелёное делает ИИ с выборочной проверкой.

## Что внутри

- Метод как данные: `src/method/asdic.ts` (5 этапов, 30 уровней, требования, поля, правила).
- Планы, записи, история правок, подписи красных решений, закрытие этапов человеком.
- Источники: PDF, DOCX, MD, TXT, CSV, заметки и страницы. Каждая цитата ИИ сверяется с текстом источника, непроверяемые отбрасываются.
- ИИ: черновики записей, три варианта для красных решений (сначала слабые места), улучшение записи, критика, поиск в интернете.
- Документы этапа: PDF, Word, Markdown; каждая сборка хранится версией.
- Журнал вызовов ИИ: `/admin/ai` (модель, токены, стоимость, ошибки, итог для человека).
- Бесплатный классификатор задач без входа: `/classify`.
- Визуальные концепции (Design, 🟡): ИИ собирает бриф из утверждённых записей плана. Claude верстает по нему бренд-борд или макет кодом, а человек принимает результат, берёт его как основу или отклоняет.
- Подбор каналов (Interaction → «Каналы и медиаплан», 🟡): каналы делятся на «нужен», «позже» и «не нужен». По каждому каналу ИИ даёт задачу на шаге пути, инструменты и обоснование со ссылками на записи плана.

## Слой ИИ

Операции (`src/lib/ai/ops.ts`) знают только интерфейс `AIProvider` из `src/lib/ai/provider.ts`. Провайдер выбирается переменной `AI_PROVIDER`; сейчас есть `claude` (`src/lib/ai/providers/claude.ts`). Чтобы подключить другого провайдера (например, модель на серверах в РФ), нужен один файл-адаптер с методами `structured` и `webResearch` и строка в `provider()`. Если провайдер не умеет искать в интернете, кнопки поиска скрываются сами.

## Визуалы

Визуалы концепций по умолчанию делает Claude кодом (`src/lib/images/providers/claude.ts`):
- мудборд и концепт: бренд-борд в HTML. В нём знак в SVG, версии знака от 96 до 16 px, семейство под продукты, палитра с HEX, шрифт, пример применения и принципы;
- креатив, пост, первый экран: макет SVG точного размера с настоящим текстом.

Скрипты в визуалах вырезаются (`src/lib/images/sanitize.ts`), а сами визуалы открываются в песочнице. Из внешних ресурсов разрешены только шрифты Google Fonts. Скачать визуал можно в PNG (растеризует Chromium), SVG или HTML.

Внешний генератор картинок включается только явно: `IMAGE_PROVIDER=yandexart` (Россия), `openai` (международный контур) или `mock` (тестовая заглушка). Каждый вызов пишется в журнал ИИ со стоимостью.

## Тарифы, кредиты и оплата

Каждая ИИ-операция списывает кредиты по реальной себестоимости из журнала ИИ × 3,5 (1 кредит = $0,10). Перед запуском видна оценка и остаток, при нехватке ИИ не запускается и ведёт на `/billing`. Тарифы, цены, наценка и оценки операций задаются в `src/lib/billing/tiers.ts`.

- Free: 30 кредитов при регистрации, 1 план. Pro $49 (400 кредитов, 5 планов), Команда $149 (1 500), Консультант $249 (3 000). За год платят 10 месяцев.
- Кредиты тарифа пополняются раз в месяц до нормы и не копятся; купленные пакеты (100 за $12, 500 за $50) не сгорают и тратятся вторыми.
- Оплата через Paddle (merchant of record: сам продаёт и платит налоги). Подключение: ключи в окружение, затем кнопка «Создать тарифы в Paddle и подключить вебхук» на `/admin/billing`. Там же ручное начисление кредитов и выдача тарифа.
- Paddle сообщает об оплатах вебхуком `/api/paddle/webhook` (подпись проверяется, повторы безопасны). Смена тарифа идёт через API с пересчётом, карта, счета и отмена в кабинете Paddle.

## Переменные окружения

| Переменная | Нужна | Что это |
| --- | --- | --- |
| `DATABASE_URL` | да | Postgres, например `postgres://user:pass@host:5432/asdic` |
| `AUTH_SECRET` | да | Длинная случайная строка для подписи сессий |
| `ASDIC_ANTHROPIC_API_KEY` или `ANTHROPIC_API_KEY` | для ИИ | Ключ Claude API (sk-ant-api…). Без него всё работает, кроме ИИ. Первое имя нужно там, где ANTHROPIC_* занято другим инструментом |
| `ASDIC_ANTHROPIC_BASE_URL` | нет | Адрес Claude API, по умолчанию `https://api.anthropic.com` |
| `AI_PROVIDER` | нет | `claude` по умолчанию |
| `ASDIC_MODEL` | нет | Основная модель, по умолчанию `claude-opus-5-5` |
| `ASDIC_FAST_MODEL` | нет | Быстрая модель для описаний файлов, по умолчанию `claude-haiku-5-5` |
| `IMAGE_PROVIDER` | нет | `claude` по умолчанию; `yandexart`, `openai` или `mock` включают внешний генератор |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | для YandexART | API-ключ сервисного аккаунта с ролью `ai.imageGeneration.user` и каталог Yandex Cloud |
| `OPENAI_API_KEY`, `OPENAI_IMAGE_MODEL` | для OpenAI | Ключ и модель изображений, по умолчанию `gpt-image-1` |
| `IMAGE_PRICE_USD` | нет | Цена одной картинки для журнала, если нужна точнее ориентира |
| `ADMIN_EMAILS` | нет | Почты через запятую, кому открыты журнал ИИ и админка оплаты; админы работают без списания кредитов |
| `PADDLE_ENV` | нет | `sandbox` (тестовый режим, по умолчанию) или `production` |
| `PADDLE_API_KEY`, `PADDLE_CLIENT_TOKEN` | для оплаты | Ключ API и клиентский токен Paddle (Developer tools → Authentication). Без них всё работает, только оплата не показывается |
| `PADDLE_WEBHOOK_SECRET` | нет | Секрет вебхука, если не хотите создавать его кнопкой в `/admin/billing` |
| `APP_URL` | нет | Публичный адрес сайта для вебхука, если не определяется сам |
| `SIGNUP_CODE` | нет | Если задан, регистрация только по этому коду |
| `UPLOAD_DIR` | нет | Папка для файлов, по умолчанию `./data/uploads` |
| `APP_TIME_ZONE` | нет | Часовой пояс дат на страницах, по умолчанию `Europe/Moscow` (UTC+3) |
| `CHROMIUM_PATH` | нет | Chromium для PDF, по умолчанию `/opt/pw-browsers/chromium` |

## Запуск локально

```sh
npm install
npx drizzle-kit migrate          # нужна база из DATABASE_URL
npm run dev                      # http://localhost:3000
```

## Docker

```sh
docker build -t asdic .
docker run -p 3000:3000 -e DATABASE_URL=... -e AUTH_SECRET=... -e ANTHROPIC_API_KEY=... -v asdic-data:/app/data asdic
```

Миграции применяются при старте контейнера.

## Запуск в интернете (Render)

В корне лежит `render.yaml`. На render.com: New → Blueprint → выбрать этот репозиторий → вписать `ASDIC_ANTHROPIC_API_KEY` и свою почту в `ADMIN_EMAILS` → Apply. Render сам создаст базу, сгенерирует `AUTH_SECRET`, соберёт Docker-образ, применит миграции и даст ссылку вида `https://asdic-xxxx.onrender.com`. Проверка живости: `/api/health`.

Бесплатный тариф годится для проверки: сервис засыпает через 15 минут без посещений (первое открытие ~1 минута), база удаляется через 30 дней, загруженные файлы пропадают при перезапуске. Для работы: тариф сервиса Starter с диском на `/app/data` и платная база.
